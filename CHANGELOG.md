# Changelog

## 1.0.0 - 2026-11-04

### Added
- Twig variable `craft.coworkingview.rate(city)` and `craft.coworkingview.cities()` for the public CoworkingView Price Index. No API key.
- Responses are stored in Craft’s data cache. Cache duration and display currency are editable on the plugin settings page.
- Dashboard widget and a control panel utility that show one city’s flex desk, dedicated desk, private office, day pass and meeting room prices.
- Attribution for the CoworkingView Price Index (CC BY 4.0) is included on every result.
